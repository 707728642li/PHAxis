# Governance

Maintainer and GitHub account assignments await owner confirmation. No account is inferred from this workstation.
Scientific algorithm/threshold changes require reviewed numerical regression and a model/contract change record. Packaging/UI changes require build and user-journey tests. Source, weights and data are approved separately.
Semantic versioning applies to software; model and output schemas are independently identified. Deprecations should warn for at least one minor release. Response times and long-term support are not promised until maintainers accept them.
