# Troubleshooting

**Wrong package/version:** do not install the research-root pyproject.toml, which belongs to legacy RHAxis. Install the independent PHAxis wheel.

**Missing Torch or model files:** the lightweight installation runs demo/report; production inference needs `[deployment]` and the separate, hash-bound model capsule.

**Existing output:** choose a new directory. `--resume` belongs to a bound interrupted analysis, not to report/demo overwriting.

**Manifest mismatch:** check hashes, task IDs and calibration; do not silently edit a sealed manifest.

**No measured hair length:** hair identities can be present without endpoint-supported complete curves. Inspect support and reason fields rather than substituting zeros.

**Support:** send minimal synthetic reproduction, software version and sanitized error text. Omit private images, workstation paths and credentials.
