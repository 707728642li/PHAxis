# PHAxis 根毛身份与几何评价协议（2026-08-28）

## 适用范围

HumanCurated443 的根毛人工真值是每条根毛的一条单实例中心线折线，不是具有人工宽度的稠密区域。PHAxis 因此把“是否识别到一条真实根毛”和“是否完整复刻该根毛的全部可见几何”分成两个问题，不以逐像素中心线 F1 单独决定模型是否具有植物学可用性。

44 张锁定 QC-development 图仅用于开发评价和工作点选择；它们不构成覆盖层隐藏的独立准确率。所有指标均按图像 `task_id` 汇总，保持既定 family_key 隔离，不读取 blind/final-validation 数据。

## 预先锁定的指标层级

### 1. 植物学主指标：单根毛生物学存在

每个预测与每个人工根毛进行一对一 Hungarian 匹配，禁止一个预测重复解释多条人工根毛，也禁止多个预测重复解释同一根毛。预测两点存在向量与人工单中心线均在物理空间重采样；在 5、10、20 µm 容忍半径下，预测侧和真值侧各至少 25% 的采样点获得对方曲线支持、且近端方向不相反，即视为同一条真实根毛。20 µm 是预先锁定的主报告工作点，5 和 10 µm 是定位敏感性分析。

这一匹配不要求 distal endpoint 对齐、全线重合或人工起点位置完全一致。它直接回答“模型是否找到了人工所标的这根毛”，而不是“模型是否逐像素复刻了人工画线”。

主表至少报告：

- 生物学存在 precision、recall、F1；
- 每图 count MAE、bias、Pearson r 和 CCC；
- 稀疏、中等、密集和极密图像分层；
- Q2/Q3/Q4 标注质量分层；

总体点估计与 Stage-B-minus-legacy 差值均使用固定随机种子 `20260828` 的 10,000 次配对图像级非参数 bootstrap 给出 95% 区间。重采样单位是整张 source image/root，而不是 3,800 条根毛；同一次重复中两个专家使用相同的图像索引。

这个层级回答的是“预测是否对应一条实际人工标记的根毛”。预测线允许比人工中心线略短、略长或局部偏移，不要求逐点重合，也不把人工起点在根内放置深浅的差异误当成模型错误。

### 2. 附着与轴向部署指标

正式附着保证必须复用第 1 节产生的 20 µm 生物学存在一对一匹配，禁止为附着结果另做一个更有利的 base-only rematch。对这些固定身份配对再判断 attachment 是否位于 20 µm 内，并以原始预测数和人工根毛数为分母报告 attachment-qualified precision、recall、F1；正式身份配对的 attachment 误差另报告中位数和 P95。这样“找对了哪条根毛”和“附着点定位到什么精度”共享同一个身份账本。

正式工作点选择使用固定 0.10 score floor 下、一次网络前向产生的不可变 base→tip 直线存在代理池，并直接最大化第 1 节同义的 20 µm 一对一 tolerant biological-presence F1；并列时依次最小化逐图 count MAE、绝对 signed bias，再选择更高的预声明阈值。Base/attachment 5、10、20 µm 结果只用于定位敏感性，不参与阈值选择，也不得称为正式附着准确率。Distal endpoint error、conditional length、complete-line overlap 与人工根毛线宽都不是工作点 Gate。由同一生物学身份匹配派生正式附着指标、附着侧别正确率、沿有序主根轴的位置误差、first-hair 距离稳定性和局部窗口密度。

### 3. 几何次指标：严格中心线对应

严格匹配额外检查极性、预测/真值长度比、平均曲线距离与 Hausdorff 上界。它用于发现反向、半截、零长度和跨根毛错误，不作为植物学身份的唯一主指标。

报告：严格 presence F1、远端 endpoint error、匹配长度 MAE/bias、轨迹连续率。该层级的数值预期低于或接近身份层级；论文中必须明确它是几何诊断，而不是“是否存在该根毛”的唯一判据。

### 4. 场级诊断：容忍中心线 precision/recall/F1

中心线热图或骨架在物理容忍带内的像素/点级 F1 只用于定位网络与拼接问题。人工没有标注根毛宽度，因此不得把膨胀中心线解释为人工根毛区域，不得用该指标替代实例身份和计数结果。

## PHAxis Hybrid-Max 的职责边界

- Stage-B 专家决定根毛身份、附着和数量；
- Hybrid-Max 的 endpoint-complete 曲线只有在与 Stage-B 身份一对一匹配后，才提供正式长度和依赖长度的表型；
- Stage-B 的两点存在向量不是完整中心线，不能直接作为正式根毛长度；
- 旧 Hybrid 身份与 Stage-B 身份不做无门控 union；
- 灰白、弯折和密集区通过训练特征、物理尺度重采样、根邻域门控及置信度解码提高召回，而不是无限降低阈值。

## 论文呈现规则

论文正文优先呈现生物学存在 F1、count MAE/CCC、附着位置和植物学表型一致性；严格曲线与场级 F1 放在方法验证或补充材料中。任何 44 图结果均标为 overlay-visible development evidence。正式泛化准确率仍需未来锁定、未参与开发的外部数据集确认。

历史语义复核中，相同 44 图和 matcher 下，legacy five-fold OOF Stage-B 与旧 Hybrid endpoint-complete identity layer 的 20 µm F1 分别为 `0.883510` 与 `0.796403`。这两个数字只保留为非发布的历史协议复核，不得进入 PHAxis 1.0.0 最终图表或替代最终 train399 五 seed 结果；历史五折集合曾覆盖全部 443 张开发图，因此也不能作为独立准确率。
