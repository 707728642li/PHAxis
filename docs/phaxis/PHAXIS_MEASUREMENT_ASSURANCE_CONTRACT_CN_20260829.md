# PHAxis 1.0.0 主根连续性、根毛附着与物理尺度保证合同

本文固定 PHAxis 论文和发布包中三类几何保证证据的科学含义。它们均来自
HumanCurated443 的 44 张 QC-development 图像，只用于开发域测量保证与模型选择，
不得表述为独立外部测试准确率。人工根毛真值是一条单中心线主干，不是根毛宽度或
稠密区域真值；根冠只使用一个 distal/root-cap 点，不评价范围不稳定的根冠区域。

## 1. 主根连续性

评价对象是最终表型提取实际接收的、已封存的 fused 主根前景。PHAxis 正式流程自身的
连续性补全如果被采用，必须已经体现在该最终前景及其上游哈希中；评价器只对最终前景
逐连通分量骨架化，不在评分阶段插值、桥接或补线。

参考轴由 canonical vector 主根多边形和人工 distal 点确定，并在物理坐标中按不超过
2 µm 的间隔采样。默认支持容差为 5 µm。正式连续性至少同时报告：

- 参考轴覆盖率；
- 任一单一预测连通分量能够达到的最大覆盖率；
- 最佳单分量上的最长不支持缺口；
- `break_free` 图像比例；
- 可见轴向跨度的绝对误差。

`break_free` 只在至少一个**同一连通分量**支持整条参考轴时成立。多个断片即使联合覆盖
率为 1，也不得算作连续；这类情况须由 `union_coverage_hides_fragmentation` 明确记录。
联合覆盖及联合缺口只作为诊断，不能替代单分量连续性结论。

## 2. 根毛身份与附着

根毛主指标回答“预测与人工中心线是否代表同一根毛”。预测和人工曲线均按弧长重采样，
在 20 µm 容差下要求双向支持均不低于 25%，且近端方向不相反，然后做确定性一对一匹配。
远端点重合、全线逐像素重合和完整长度一致不作为身份检出硬门。

附着保证分成两个不能混用的证据层：

1. 5/10/20 µm 的 attachment/base 点匹配只用于阈值选择和定位敏感性，名称固定为
   `attachment proxy`；
2. 正式附着结果复用上述生物学身份的一对一匹配，不允许另做更有利的 base-only
   rematch。正式报告 attachment-qualified precision/recall/F1，以及这些正式身份匹配的
   attachment 位置误差中位数和 P95。

因此，“检测到同一真实根毛”和“附着点达到 20 µm 定位要求”是相关但不同的量；论文表格
和图注必须同时给出分母与容差，不得把阈值选择代理包装成正式准确率。

## 3. 物理尺度

QC-development44 中，38 张图具有可见且标注的比例尺线，6 张图使用受信任元数据尺度；
两类合计必须严格等于 44。尺度保证分别报告：

- 可见比例尺检测覆盖率；
- 检出比例尺的线端点几何定位误差；
- 条件于有效检测/受信任校准的 µm px⁻¹ 相对误差；
- 适用性与 fail-closed 状态。

当前 QC-development44 没有“比例尺不存在且元数据不受信任”的样本，因此对缺失尺度的
经验 fail-closed specificity 必须写为
`not_estimable_no_absent_or_untrusted_scale_cases`，不得生成虚构的数值 specificity。
软件层 fail-closed 合同仍由负例单元测试验证，但必须与数据域经验估计分开。

## 4. 不确定性与证据身份

所有区间统一使用 10,000 次、seed `20260828` 的双侧 95% percentile bootstrap，重采样
单位是 source image。根毛误差随被抽中的整张图成组进入每次重复，单根毛不能作为独立
bootstrap 单位。每项结果必须保存图像级充分统计量、参考与预测 artifact SHA-256、输入
集合身份、实现文件 SHA-256、显式分母和证据角色。

正式证据必须满足：`blind_images_used=0`、QC-development 标签未进入梯度、没有把 provider
字节等价冒充准确率、没有根冠区域统计、没有调用或复制 pyRootHair。任何来源哈希、分母、
坐标空间、匹配合同或公共模型身份漂移均应 fail closed。

## 5. 论文解释边界

这三类结果支持的结论是：PHAxis 在已标注开发域中能够建立可审计的连续主根坐标、根毛
身份/附着关系和物理单位，从而支撑 19 项主根描述符、13 项根毛描述符及 distal-axis
profile。它们不证明跨实验室、跨设备或跨物种泛化，也不能替代未来 SHA-隔离的外部测试。
